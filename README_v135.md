## 内容
1. 共有風をSupabaseへ保存・読込
   - 保存単位: 日付 + 開催場 + レース
   - ログイン済み利用者が入力した風を全利用者で共有
   - 後から上書き可能
2. 1R〜12R一括記録は確定後データではなく、サーバーに凍結した締切前スナップショットを使用
3. AI買い目は `締切前スナップショット + 最新の共有風` で再生成
4. 締切前スナップショットがないレース、風未設定レースは誤った代替データを使わずスキップ
5. チルト -0.5〜3.0対応を維持

## 使用方法
風を変更した後に一括記録を再実行すると、そのレースの旧一括記録を置換し、最新の共有風で生成した買い目を保存します。
