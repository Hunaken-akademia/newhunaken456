# WAKE v140 + v138 統合版

この版は、以下を1つの `src/App.jsx` に統合しています。

- v140 展開リハーサル → シナリオ・対抗・穴への連動
- リハーサル確率設計のレビュー修正
  - 負のSTを `Math.abs()` で高速STへ変換しない
  - 外コース一律 -0.01秒補正を撤廃
  - 攻め手確定後に決まり手抽選
  - 同一艇は最大2シナリオ
- v138 本線・対抗逆転対策
  - `BATCH_CAPTURE_VERSION = 4`
  - v3以下の一括記録を除外・削除
  - 画面表示スナップショットのみ保存
  - iframeでの別AI再計算を廃止
  - 圧縮買い目を完全展開して保存

## 反映方法

1. この `App.jsx` を既存リポジトリの `src/App.jsx` に上書き
2. GitHubへコミット
3. Vercelのデプロイ成功を確認
4. Safariを完全終了して再度開く
5. 各レース画面でAI買い目を表示後、一括記録を実行

## 注意

- 旧v3以下の一括記録から、当時画面に表示されていた正しい買い目を復元することはできません。
- この環境にはプロジェクト全体の `package.json` / `node_modules` がないため、Vite本番ビルドは未実施です。
- TypeScriptパーサーによるJSX構文確認は通過しています。
