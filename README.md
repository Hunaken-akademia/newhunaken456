# 一括記録のレースずれ完全対策

## 原因
非表示iframeが次レースを読み込む途中で、前レースのAI買い目が一瞬残り、その買い目を次のレース番号で保存することがありました。
そのため、12Rの本線 `1-2-5` が10Rへ保存されるようなズレが発生していました。

## 修正
- 対象レースのデータ読込完了キーが一致するまで保存しない
- 各iframeに一意のcaptureTokenを付与
- 親画面は現在のiframe・トークン・日付・場・Rが全一致したメッセージだけ受理
- 保存データへbatchCaptureVersion=2と元レース情報を記録
- 旧方式の一括記録は収支集計から除外
- 一括記録を再実行すると、その日・場の旧一括記録を削除して正しく作り直す
- フォーメーション判定は完全展開のまま維持

## 修復手順
1. `src/App.jsx`を上書きしてデプロイ
2. 対象の日付・開催場を選ぶ
3. 「1R〜12Rを一括記録」をもう一度押す
4. 完了後、10Rの誤的中が消え、12Rの対抗 `4-1-2356` は結果 `4-1-2`で的中になります
