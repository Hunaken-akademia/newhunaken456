# 舟券収支保存修正＋1R〜12R一括記録

## 3レース目以降が保存できない問題
通常の「買い目購入を記録する」時に、舟券履歴だけでなく廃止済みのAI予想データ一式も別領域へ保存していました。
この重い重複保存を削除し、実際に購入記録へ追加した買い目だけを保存します。

## 一括記録
- 風を設定済みの1R〜12Rを順番に処理
- 各レース固有のAI予想を使用
- 現在の点数設定を適用
  - 例：本線4・対抗4・穴2
- 1点100円で舟券収支へ記録
- 同じ日・場・R・区分を再実行した場合は重複せず置き換え
- 展示未公開などAI予想を取得できないレースはスキップ
- AI予想のサーバー自動保存は行いません
