# 画面表示買い目をそのまま後から保存

- 通常画面に実際に表示されたAI買い目を、舟券履歴とは別の下書きとして端末内に保存
- 一括記録時は、同じ日付・場・R・風の表示済み下書きを最優先で使用
- 表示済み下書きがない場合のみ、従来の非表示取得結果を使用
- 保存レコードに `batchCaptureSource` を追加
  - `visible_ai_panel`: 画面表示済み買い目を保存
  - `capture_fallback`: 従来方式による取得
- 正式な舟券履歴への保存は、一括記録ボタンを押した時だけ

## 上書き先
`src/App.jsx`

## 注意
この版を反映する前に表示した過去レースの買い目は、端末内に下書きが存在しません。
反映後にレース画面を開き、AI買い目が表示されたレースから下書き保存が始まります。
