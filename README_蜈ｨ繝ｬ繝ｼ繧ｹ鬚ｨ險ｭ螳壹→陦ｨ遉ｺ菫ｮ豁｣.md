# 全レース風設定・AI予想保存表示修正

## 上書きするファイル
- `src/App.jsx`
- `api/yoso.js`

## 変更内容
- 1R〜12Rの風をそれぞれプルダウンで手動設定
- 選択した風を既存の `yoso_cache` にSupabase保存
- GitHub Actionsのヘッドレス画面も保存済みのレース別風を読み込み、AI評価へ反映
- 風が未設定のレースは、誤った無風扱いでAI買い目を保存しない
- AI予想保存件数を、結果確定前の保存済みレースも含めて表示
- 保存済みレース番号も表示

## SQL
追加SQLはありません。既存の `yoso_cache` を使用します。
