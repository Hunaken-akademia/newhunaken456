# WAKE UI折りたたみ改修

## 変更内容
- 1〜6号艇の選手カードを初期状態で折りたたみ
- 各艇カードに個別の開閉ボタンを追加
- 「すべて開く」「すべて閉じる」を追加
- 折りたたみ時も艇番・選手名・級別/登録番号・実進入・モーター3連率を要約表示
- イン逃げ信頼度、ST優位、2C壁性能、3C攻撃警戒などの説明欄を初期状態で折りたたみ
- 舟券収支記録UIを非表示化（既存の保存データと内部処理は削除せず保持）

## 触っていないもの
- 予想ロジック
- 認証・決済
- Supabaseテーブル
- 自動取得処理
- 既存の保存データ

## 確認項目
1. 初回表示で6艇すべて閉じている
2. 各艇の▼/▲で個別に開閉できる
3. 「すべて開く」「すべて閉じる」が6艇すべてに効く
4. 開いたカード内のコース、チルト、ST、F、体重、モーター、枠別成績を操作できる
5. 指標説明が「？ 指標の見方・計算方法」で開閉できる
6. 舟券収支記録ブロックが画面に表示されない
