【変更内容】
1. 開催場AI予想収支のAPIが race 未指定で弾かれていた順序バグを修正
   「race は1〜12を指定してください」は解消されます。

2. 点数を項目別に選択可能
   本線：1〜6点
   対抗：1〜12点
   穴：1〜12点
   組み合わせ行は各項目で選んだ点数を使って集計します。

3. 全開催場のAI買い目を自動保存
   ログイン済みツールが開いている間、全開催場の次Rを締切30分前から
   hidden iframeで順番に取得し、AI買い目を自動保存します。
   場・レースを手動選択して保存する必要はありません。

4. 結果・確定オッズの取得強化
   GitHub Actionsは締切後90分まで結果・確定オッズを再確認します。
   締切直後に未確定なら、同一run内でも20秒後に1回再確認します。

「ログイン済みのツールがブラウザで開いている間」に動作します。
完全な24時間無人サーバー保存にするには、AI評価ロジックをサーバー共通モジュールへ
分離する別改修が必要です。

paid_users / Stripe / Webhook / Googleログイン / 認証ゲート / 既存クラウド保存データは変更していません。
