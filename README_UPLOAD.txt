【即時復習表示＋ナイター展示取得改善】

上書きするファイルは4つです。

1. src/App.jsx
2. api/yoso.js
3. pipeline/capture_all_active_races.mjs
4. .github/workflows/capture-all-active-races.yml

SQLの追加実行はありません。
既に作成した race_review_snapshots テーブルをそのまま使います。

変更内容
- 終了済みレースの確定スナップショットを日単位で先読み
- 先読み内容を端末のlocalStorageにも保存
- 復習レースを選んだ瞬間に保存済みデータを表示
- 裏で最新の確定スナップショットを確認して更新
- 展示・体重・チルト・平均ST・モーターは保存済み固定データを使用
- オッズは締切後にfinal=trueで保存された120通りを使用
- ナイター場を含め、締切30分前から取得対象に拡大
- 開催状況確認を3分ごとから1分ごとへ短縮
- 取得対象数を8件から14件へ拡大
- GitHub Actionsの同時取得数を3から5へ拡大
- 締切15分前以降で展示が6艇揃わない場合、同じrun内で35秒後に再確認

安全範囲
- paid_users変更なし
- Stripe変更なし
- Googleログイン変更なし
- Supabase認証・購入者判定変更なし
- DELETE/TRUNCATEなし

確認方法
1. 4ファイルを同じ場所に上書きしてCommit
2. capture-all-active-racesを手動実行
3. 終了済みレースを一度表示
4. 別レースへ切り替えた際、保存済みデータが即時表示されることを確認

注意
初回アクセス直後だけは日単位の復習データ先読み通信が必要です。
同じ日付の2回目以降は端末保存から即時表示されます。
