# WAKE v144｜展開リハ最大12点

`src/App.jsx` を同梱の `App.jsx` で上書きしてください。

## 今回の変更

「展開リハ」カードの対象艇を、次の条件に変更しました。

1. 展開リハーサルの艇別頭率が3位以内
2. 頭率8%以上
3. 本線・対抗で頭として採用されていない
4. 条件に該当する艇がなければカード自体を表示しない
5. 1艇なら最大12点、2艇なら各6点（合計最大12点）

買い目の重複除外は、従来どおり本線・対抗・穴の全買い目を対象にします。
旧 `reh × (1 - cov / 4)` の抜けスコア方式は廃止しました。

## 維持している修正

- `Math.abs(e.st)` の撤廃
- 外コース一律 `-0.01秒` 補正の撤廃
- 最終攻め手確定後に、まくり／まくり差しを抽選
- 一括記録、上段追加、旧記録置換、点数設定、的中率・収支集計の「展開リハ」対応
- `BATCH_CAPTURE_VERSION = 4` と表示スナップショット保存方式
- 旧「伏兵」履歴は「展開リハ」に合算
